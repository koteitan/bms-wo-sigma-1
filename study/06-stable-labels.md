このノートは、BMS の停止性の証明のうち、組合せの層を説明する。この層の中心は、DH の論文（[論文 PDF](https://googology.fandom.com/ja/wiki/%E3%83%95%E3%82%A1%E3%82%A4%E3%83%AB%3ABM4%28%E4%BD%9C%E6%88%90%E8%80%85%E6%83%85%E5%A0%B1%E4%BB%98%E3%81%8D%29.pdf)）の定義 18.1 と命題 19.1 である。

この層は、ラベルの集合と関係の族 $`(\mathrm{rel}_k)_{k \in \mathbb N}`$ を引数に取る（§1）。ラベルが何であるかは使わない。ラベルについての 3 つの条件から、展開で高さが下がることを示す（§3〜§6）。高さが下がれば、展開は止まる（§8）。このリポジトリは、この層の定理をそのまま使う。3 つの条件を満たすラベルを与えるのは、意味の層の仕事である（§9）。

## 1. ラベルの約束

$`r \in \mathbb N`$ を配列の行数とする。

**定義（ラベルの約束）.** 行数 $`r`$ の **ラベルの約束** とは、組 $`(\mathrm{Lab}, \lt, (\mathrm{rel}_k)_{k \in \mathbb N})`$ で、次を満たすものである。

- $`\mathrm{Lab}`$ は集合である。$`\mathrm{Lab}`$ の元を **ラベル** と呼ぶ。
- $`\lt`$ は $`\mathrm{Lab}`$ の上の整列順序である（[01](01-ordinals.md) §1）。特に $`\lt`$ は整礎である（[02](02-well-founded.md) §1）。
- $`k \in \mathbb N`$ ごとに、$`\mathrm{rel}_k`$ は $`\mathrm{Lab}`$ の上の 2 引数の関係である。§2 で、行 $`k`$ の先祖の関係にある 2 つの列のラベルに、この関係を求める。
- 次の条件 1〜3 が成り立つ。

**条件 1（狭義性）.** どの $`k`$ と $`a, b \in \mathrm{Lab}`$ でも次が成り立つ。

```math
\mathrm{rel}_k(a, b) \implies a \lt b
```

**条件 2（推移律）.** どの $`k`$ と $`a, b, c \in \mathrm{Lab}`$ でも次が成り立つ。

```math
\mathrm{rel}_k(a, b) \ \wedge\ \mathrm{rel}_k(b, c) \implies \mathrm{rel}_k(a, c)
```

**条件 3（有限反映）.** 次の 4 つの仮定がすべて成り立つとする。

- $`n \lt r`$ で、$`\mathrm{rel}_n(\alpha, \beta)`$ である。
- $`X \subseteq \mathrm{Lab}`$ は有限集合で、どの $`x \in X`$ も $`x \lt \alpha`$ である。
- $`s \gt 0`$ で、$`y_0 \lt y_1 \lt \cdots \lt y_{s-1}`$ はラベルである。
- どの $`i \lt s`$ でも $`\alpha \le y_i \lt \beta`$ である。

このとき、ラベル $`y'_0, \ldots, y'_{s-1}`$ で、次の (R1)〜(R6) を満たすものがある。表の文字は、$`i, j \lt s`$、$`k \lt r`$、$`m \lt n`$、$`x \in X`$ を動く。

| 番号 | 結論 |
|---|---|
| (R1) | $`y'_0 \lt y'_1 \lt \cdots \lt y'_{s-1}`$ |
| (R2) | $`y'_i \lt \alpha`$ |
| (R3) | $`x \lt y'_0`$ |
| (R4) | $`\mathrm{rel}_k(x, y_i) \implies \mathrm{rel}_k(x, y'_i)`$ |
| (R5) | $`\mathrm{rel}_k(y_i, y_j) \implies \mathrm{rel}_k(y'_i, y'_j)`$ |
| (R6) | $`\mathrm{rel}_m(y_i, \beta) \implies \mathrm{rel}_m(y'_i, \alpha)`$ |

**読み方.** 区間 $`[\alpha, \beta)`$ の中の有限個のラベル $`y_i`$ を、$`\alpha`$ より下のラベル $`y'_i`$ に移す（R2）。

- $`X`$ の元との順序と関係は保たれる（R3、R4）。
- $`y_i`$ どうしの順序と関係は保たれる（R1、R5）。
- 上端 $`\beta`$ への関係は、新しい上端 $`\alpha`$ への関係として保たれる（R6）。ただし、行 $`n`$ より下の行 $`m`$ だけである。
- (R4) と (R5) は、すべての行 $`k \lt r`$ で成り立つ。

これは [04](04-patterns-of-resemblance.md) の有限反映の形である。DH の論文では定理 17.1 にあたる。

**注意.** 関係 $`\mathrm{rel}_k`$ は $`k \ge r`$ でも定義されている。しかし使うのは $`k \lt r`$ だけである。

**例（空の関係）.** どの $`\mathrm{rel}_k`$ も空の関係とする。条件 1、2 は、仮定 $`\mathrm{rel}_k(a, b)`$ が偽なので成り立つ。条件 3 も、仮定 $`\mathrm{rel}_n(\alpha, \beta)`$ が偽なので成り立つ。よってこれはラベルの約束である。ただし、§2 の安定なラベルを持つ配列は、先祖の関係が 1 つも無い配列だけになる。役に立つラベルの約束は [07](07-relation-r.md) と [09](09-obligations.md) で作る。

## 2. 安定なラベルと高さ

このノートでは、配列 $`A`$ で列 $`i`$ が行 $`k`$ で列 $`j`$ の先祖であることを $`i \prec^A_k j`$ と書く（先祖は [05](05-bms.md)）。$`i \preceq^A_k j`$ は $`i = j`$ または $`i \prec^A_k j`$ のことである。

**定義（安定なラベル、DH の定義 18.1）.** $`A`$ を $`r`$ 行、長さ $`\ell`$ の配列とする。関数 $`f : \{0, \ldots, \ell - 1\} \to \mathrm{Lab}`$ が $`A`$ の **安定なラベル** であるとは、次の 2 つが成り立つことをいう。

| 番号 | 条件 |
|---|---|
| (S1) | $`i \lt j \lt \ell \implies f(i) \lt f(j)`$ |
| (S2) | $`k \lt r`$ かつ $`i \prec^A_k j`$ なら $`\mathrm{rel}_k(f(i), f(j))`$ |

$`f(i)`$ を列 $`i`$ のラベルと呼ぶ。

**定義（高さ）.** $`A`$ が空でないとき、最後の列のラベル $`f(\ell - 1)`$ を $`f`$ の **高さ** と呼び、$`\mathrm{ht}(f)`$ と書く。

**例.** $`A = (0,0)(1,1)(2,2)(3,2)`$ とする。$`r = 2`$、$`\ell = 4`$ である。親と先祖は次のとおりである（計算機で求めた）。

| 列 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 成分 | $`(0,0)`$ | $`(1,1)`$ | $`(2,2)`$ | $`(3,2)`$ |
| 行 0 の親 | 無し | 0 | 1 | 2 |
| 行 1 の親 | 無し | 0 | 1 | 1 |

- 行 0：列 $`j`$ の親は、行 0 の成分が小さい列のうち、$`j`$ より左で最も右のものである。ここでは列 $`j - 1`$ である。よって $`i \lt j`$ ならいつも $`i \prec^A_0 j`$ である。
- 行 1：親の候補は、行 0 での先祖である。列 3 の行 1 の成分は 2 である。候補のうち、列 2 の成分は 2 で小さくない。列 1 の成分は 1 で小さい。よって列 3 の親は列 1 である。
- 行 1 の先祖の組は $`(0,1)`$、$`(0,2)`$、$`(0,3)`$、$`(1,2)`$、$`(1,3)`$ である。$`(2,3)`$ は入らない。

したがって $`f`$ が安定なラベルであるとは、次のことである。

```math
f(0) \lt f(1) \lt f(2) \lt f(3)
```

```math
\mathrm{rel}_0(f(i), f(j)) \quad (0 \le i \lt j \le 3)
```

```math
\mathrm{rel}_1(f(0), f(1)),\quad \mathrm{rel}_1(f(0), f(2)),\quad \mathrm{rel}_1(f(0), f(3)),\quad \mathrm{rel}_1(f(1), f(2)),\quad \mathrm{rel}_1(f(1), f(3))
```

$`\mathrm{rel}_1(f(2), f(3))`$ は求めない。高さは $`\mathrm{ht}(f) = f(3)`$ である。

## 3. 命題 19.1

以下、条件 1〜3 を満たすラベルの約束を 1 つ固定する。

**定理（高さの降下、DH の命題 19.1）.** $`A`$ を空でない $`r`$ 行の配列、$`f`$ を $`A`$ の安定なラベルとする。$`N \in \mathbb N`$ で、$`A[N]`$ が空でないとする。このとき、$`A[N]`$ の安定なラベル $`g`$ で、次を満たすものがある。

```math
\mathrm{ht}(g) \lt \mathrm{ht}(f)
```

$`c = \ell - 1`$ を $`A`$ の最後の列とする。証明は、$`c`$ が親を持つかどうかで 2 つの場合に分ける（§4、§5〜§6）。

どちらの場合も、次の性質を使う。

**性質 1（接頭辞）.** 配列 $`D`$ の最初のいくつかの列からなる配列を、$`D`$ の **接頭辞** と呼ぶ。接頭辞での列の親と先祖は、$`D`$ での親と先祖と同じである。

**理由.** 列の親は、その列の成分と、それより左の列の成分だけから決まる（[05](05-bms.md)）。先祖も同じである。$`\square`$

## 4. 場合 1：最後の列に親が無いとき

どの行 $`k \lt r`$ でも列 $`c`$ が親を持たないとする。このとき $`A[N]`$ は、$`A`$ から最後の列を消した配列である（[05](05-bms.md)）。

- $`A[N]`$ は $`A`$ の接頭辞である。性質 1 から、親と先祖は $`A`$ でのものと同じである。
- よって $`f`$ を列 $`0, \ldots, c - 1`$ に制限したものが、$`A[N]`$ の安定なラベルである。これを $`g`$ とする。
- $`A[N]`$ は空でないので $`c \ge 1`$ である。(S1) から $`\mathrm{ht}(g) = f(c - 1) \lt f(c) = \mathrm{ht}(f)`$ である。$`\square`$

**例.** $`A = (0,0)(0,0)(0,0)`$ では、どの列もどの行でも親を持たない。$`A[3] = (0,0)(0,0)`$ である（計算機で求めた）。

## 5. 場合 2 の準備

列 $`c`$ が、ある行 $`k \lt r`$ で親を持つとする。[05](05-bms.md) の展開の記号を、このノートで使う形で書き直す。

- $`m_0`$：列 $`c`$ が親を持つ行のうち、最大のもの。$`m_0 \lt r`$ である。
- $`p`$：行 $`m_0`$ での列 $`c`$ の親。これが悪い根である。
- $`s = c - p`$。$`s \ge 1`$ である。
- $`G`$：列 $`0, \ldots, p - 1`$。
- $`B_0`$：列 $`p, \ldots, c - 1`$。これを悪い部分と呼ぶ。

展開 $`A[N]`$ は、$`G`$ のあとに $`B_0`$ の写しを $`N + 1`$ 個並べた配列である。

```math
A[N] = G \frown B_0 \frown B_1 \frown \cdots \frown B_N
```

各 $`B_q`$ は $`s`$ 個の列を持つ。写しの成分の値は、[05](05-bms.md) の展開の規則で決まる。このノートでは値の規則を直接は使わない。使うのは下の性質 2 だけである。

$`B_q`$ の $`j`$ 番目の列（$`j \lt s`$）の番号を、次のように書く。

```math
\langle q, j \rangle = p + q \cdot s + j
```

$`q \le N`$ なら、$`A[q] = G \frown B_0 \frown \cdots \frown B_q`$ は $`A[N]`$ の接頭辞である。

**性質 2（写しの補題、DH の定理 6.3 と系 6.12）.** $`q + 1 \le N`$、$`j \lt s`$、$`k \lt r`$ とする。$`A[N]`$ で $`i \prec_k \langle q+1, j \rangle`$ なら、次の (a)〜(d) のどれかが成り立つ。

| 場合 | 先祖 $`i`$ の場所 | 成り立つこと |
|---|---|---|
| (a) | 同じブロック：$`i = \langle q+1, i' \rangle`$、$`i' \lt j`$ | $`p + i' \prec^A_k p + j`$ |
| (b) | $`G`$：$`i \lt p`$ | $`i \prec^A_k p + j`$ |
| (c) | 2 つ以上前のブロック：$`i = \langle a, i' \rangle`$、$`a \lt q`$ | $`A[N]`$ で $`i \prec_k \langle q, j \rangle`$ |
| (d) | すぐ前のブロック：$`i = \langle q, i' \rangle`$ | $`k \lt m_0`$、$`p + i' \prec^A_k c`$、$`p \preceq^A_k p + j`$ |

- (a) と (b) は、先祖の関係を $`A`$ に戻す。
- (c) は、先祖の関係の子孫の側を、1 つ前のブロックの同じ位置に移す。
- (d) は、すぐ前のブロックからの先祖の関係が、行 $`m_0`$ より下の行でしか起きないことをいう。

この性質は DH の論文の §6 にある。配列の成分の計算だけによる事実で、ラベルは使わない。このノートでは証明しない。

**例（写しの補題）.** §2 の例 $`A = (0,0)(1,1)(2,2)(3,2)`$ で、$`N = 2`$ とする。列 3 は行 0 で列 2 を、行 1 で列 1 を親に持つ。よって $`m_0 = 1`$、$`p = 1`$、$`s = 2`$ である。展開は次のとおりである（計算機で求めた）。

| 列 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| ブロック | $`G`$ | $`B_0`$ | $`B_0`$ | $`B_1`$ | $`B_1`$ | $`B_2`$ | $`B_2`$ |
| 番号 | | $`\langle 0,0 \rangle`$ | $`\langle 0,1 \rangle`$ | $`\langle 1,0 \rangle`$ | $`\langle 1,1 \rangle`$ | $`\langle 2,0 \rangle`$ | $`\langle 2,1 \rangle`$ |
| $`A[2]`$ の成分 | $`(0,0)`$ | $`(1,1)`$ | $`(2,2)`$ | $`(3,1)`$ | $`(4,2)`$ | $`(5,1)`$ | $`(6,2)`$ |
| 行 0 の親 | 無し | 0 | 1 | 2 | 3 | 4 | 5 |
| 行 1 の親 | 無し | 0 | 1 | 0 | 3 | 0 | 5 |

$`q = 1`$、$`j = 1`$ として、列 $`\langle 2, 1 \rangle = 6`$ の先祖を性質 2 で分ける。

| 行 $`k`$ | 先祖 $`i`$ | 場合 | 成り立つこと |
|---|---|---|---|
| 0 | 5 | (a) | $`1 \prec^A_0 2`$ |
| 0 | 0 | (b) | $`0 \prec^A_0 2`$ |
| 0 | 1、2 | (c) | $`A[2]`$ で $`1 \prec_0 4`$、$`2 \prec_0 4`$ |
| 0 | 3、4 | (d) | $`0 \lt m_0 = 1`$、$`1 \prec^A_0 3`$、$`2 \prec^A_0 3`$、$`1 \prec^A_0 2`$ |
| 1 | 5 | (a) | $`1 \prec^A_1 2`$ |
| 1 | 0 | (b) | $`0 \prec^A_1 2`$ |

行 1 には (d) が無い。$`k = 1`$ は $`m_0 = 1`$ より小さくないからである。

## 6. 場合 2 の証明：ブロックごとの付け替え

次のように置く。

```math
\alpha = f(p), \qquad \beta = f(c), \qquad y_j = f(p + j) \quad (j \lt s)
```

- $`p`$ は行 $`m_0`$ で $`c`$ の親なので、$`p \prec^A_{m_0} c`$ である。$`m_0 \lt r`$ なので、(S2) から $`\mathrm{rel}_{m_0}(\alpha, \beta)`$ である。
- (S1) から、$`\alpha = y_0 \lt y_1 \lt \cdots \lt y_{s-1} \lt \beta`$ である。

**不変条件.** $`q = 0, 1, \ldots, N`$ の順に、$`A[q]`$ のラベル $`g_q`$ で、次の (I1)〜(I4) を満たすものを作る。

| 番号 | 条件 |
|---|---|
| (I1) | $`g_q`$ は $`A[q]`$ の安定なラベル |
| (I2) | $`i \lt p \implies g_q(i) = f(i)`$ |
| (I3) | $`j \lt s \implies g_q(\langle q, j \rangle) = y_j`$ |
| (I4) | $`i \lt \langle q, 0 \rangle \implies g_q(i) \lt \alpha`$ |

最後のブロック $`B_q`$ には、悪い部分の古いラベル $`y_j`$ がそのまま付く（I3）。それより左のラベルは、すべて $`\alpha`$ より下にある（I4）。

**$`q = 0`$ のとき.** $`A[0] = G \frown B_0`$ は、$`A`$ から最後の列を消した配列である。$`g_0`$ を、$`f`$ を列 $`0, \ldots, c - 1`$ に制限したものとする。

- (I1)：$`A[0]`$ は $`A`$ の接頭辞なので、性質 1 から成り立つ。
- (I2)、(I3)：$`g_0 = f`$ なので成り立つ。
- (I4)：$`i \lt p`$ なら、(S1) から $`f(i) \lt f(p) = \alpha`$ である。

**$`q`$ から $`q + 1`$ へ（$`q + 1 \le N`$）.** 有限反映（条件 3）を 1 回使う。引数は次のとおりである。

- $`n = m_0`$、$`\alpha = f(p)`$、$`\beta = f(c)`$。上で見たとおり $`n \lt r`$、$`\mathrm{rel}_n(\alpha, \beta)`$ である。
- $`X = \{ g_q(i) : i \lt \langle q, 0 \rangle \}`$。(I4) から、どの $`x \in X`$ も $`x \lt \alpha`$ である。
- $`y_0, \ldots, y_{s-1}`$。上で見たとおり、増加していて、$`\alpha \le y_j \lt \beta`$ である。

こうして $`y'_0, \ldots, y'_{s-1}`$ を得る。$`A[q+1] = G \frown B_0 \frown \cdots \frown B_{q+1}`$ のラベル $`g_{q+1}`$ を、次で定める。

```math
g_{q+1}(i) = g_q(i) \qquad (i \lt \langle q, 0 \rangle)
```

```math
g_{q+1}(\langle q, j \rangle) = y'_j, \qquad g_{q+1}(\langle q+1, j \rangle) = y_j \qquad (j \lt s)
```

つまり、ブロック $`B_q`$ の古いラベル $`y_j`$ を、$`\alpha`$ より下の $`y'_j`$ に付け替える。新しいブロック $`B_{q+1}`$ には、古いラベル $`y_j`$ を付ける。$`B_q`$ より左のラベルは変えない。

(I2) と (I3) は定義から成り立つ。(I4) は、$`B_q`$ より左では $`g_q`$ の (I4) から、$`B_q`$ では (R2) から成り立つ。(I1) を確かめる。

**(S1) の確かめ.** $`B_q`$ より左では $`g_q`$ の (S1) を使う。残りは、(R3)、(R1)、(R2) から次の並びになる。

```math
x \lt y'_0 \lt \cdots \lt y'_{s-1} \lt \alpha = y_0 \lt \cdots \lt y_{s-1} \qquad (x \in X)
```

**(S2) の確かめ.** $`k \lt r`$ とし、$`A[q+1]`$ で $`i \prec_k j^*`$ とする。$`A[q]`$ と $`A[q+1]`$ はどちらも $`A[N]`$ の接頭辞なので、性質 1 から、先祖の関係はどれで見ても同じである。子孫の側の列 $`j^*`$ の場所で分ける。

1. $`j^* \lt \langle q, 0 \rangle`$ のとき：$`i`$ も $`j^*`$ も $`B_q`$ より左にある。ラベルは $`g_q`$ と同じなので、$`g_q`$ の (S2) から成り立つ。
2. $`j^* = \langle q, j \rangle`$（$`B_q`$ の中）のとき：$`g_q`$ の (S2) と (I3) から $`\mathrm{rel}_k(g_q(i), y_j)`$ である。
   - $`i \lt \langle q, 0 \rangle`$ なら、$`g_q(i) \in X`$ である。(R4) から $`\mathrm{rel}_k(g_q(i), y'_j)`$ である。
   - $`i = \langle q, i' \rangle`$ なら、$`\mathrm{rel}_k(y_{i'}, y_j)`$ である。(R5) から $`\mathrm{rel}_k(y'_{i'}, y'_j)`$ である。
3. $`j^* = \langle q+1, j \rangle`$（$`B_{q+1}`$ の中）のとき：ラベルは $`y_j = f(p + j)`$ である。性質 2 の場合で分ける。
   - (a) $`i = \langle q+1, i' \rangle`$：$`p + i' \prec^A_k p + j`$ と $`f`$ の (S2) から、$`\mathrm{rel}_k(y_{i'}, y_j)`$ である。
   - (b) $`i \lt p`$：$`i \prec^A_k p + j`$ と $`f`$ の (S2) から、$`\mathrm{rel}_k(f(i), y_j)`$ である。(I2) から $`g_{q+1}(i) = f(i)`$ である。
   - (c) $`i = \langle a, i' \rangle`$、$`a \lt q`$：$`A[q]`$ で $`i \prec_k \langle q, j \rangle`$ である。$`g_q`$ の (S2) と (I3) から $`\mathrm{rel}_k(g_q(i), y_j)`$ である。$`g_{q+1}(i) = g_q(i)`$ である。
   - (d) $`i = \langle q, i' \rangle`$：ラベルは $`y'_{i'}`$ である。$`p + i' \prec^A_k c`$ と $`f`$ の (S2) から、$`\mathrm{rel}_k(y_{i'}, \beta)`$ である。$`k \lt m_0 = n`$ なので、(R6) から $`\mathrm{rel}_k(y'_{i'}, \alpha)`$ である。$`j = 0`$ なら $`\alpha = y_0`$ で終わる。$`j \gt 0`$ なら $`p \prec^A_k p + j`$ なので、$`f`$ の (S2) から $`\mathrm{rel}_k(\alpha, y_j)`$ である。推移律（条件 2）から $`\mathrm{rel}_k(y'_{i'}, y_j)`$ である。

**最後.** $`g = g_N`$ は $`A[N]`$ の安定なラベルである。$`A[N]`$ の最後の列は $`\langle N, s - 1 \rangle`$ である。(I3) と (S1) から、次が成り立つ。

```math
\mathrm{ht}(g) = y_{s-1} = f(c - 1) \lt f(c) = \mathrm{ht}(f)
```

$`\square`$

**条件の使いどころ.**

| 条件 | 使いどころ |
|---|---|
| 整列順序 | §8 の停止性（高さの無限降下列が無い） |
| 狭義性（条件 1） | 命題 19.1 の証明では使わない |
| 推移律（条件 2） | 3 の場合 (d) で $`j \gt 0`$ のとき |
| (R1)、(R2)、(R3) | 新しいラベルの順序（S1）と (I4) |
| (R4) | $`B_q`$ の列の、$`B_q`$ より左にある先祖 |
| (R5) | $`B_q`$ の中の先祖 |
| (R6) | すぐ前のブロックからの先祖（3 の場合 (d)） |

**(R6) が行 $`m \lt n`$ だけでよい理由.** (R6) を使うのは 3 の場合 (d) だけである。性質 2 から、場合 (d) は $`k \lt m_0 = n`$ のときにしか起きない。

## 7. 例

§5 の例 $`A = (0,0)(1,1)(2,2)(3,2)`$、$`N = 2`$ で、ラベルの付け替えを追う。$`m_0 = 1`$、$`p = 1`$、$`s = 2`$ なので、次のようになる。

```math
n = 1, \qquad \alpha = f(1), \qquad \beta = f(3), \qquad (y_0, y_1) = (f(1), f(2))
```

- ステップ $`q = 0`$：$`X = \{f(0)\}`$ で有限反映を使い、$`(y'_0, y'_1)`$ を得る。
- ステップ $`q = 1`$：$`X = \{f(0), y'_0, y'_1\}`$ で有限反映をもう一度使い、その結果を $`(z'_0, z'_1)`$ と書く。

| 列 | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---|---|---|---|---|---|---|
| ブロック | $`G`$ | $`B_0`$ | $`B_0`$ | $`B_1`$ | $`B_1`$ | $`B_2`$ | $`B_2`$ |
| $`g_0`$（$`A[0]`$） | $`f(0)`$ | $`f(1)`$ | $`f(2)`$ | | | | |
| $`g_1`$（$`A[1]`$） | $`f(0)`$ | $`y'_0`$ | $`y'_1`$ | $`f(1)`$ | $`f(2)`$ | | |
| $`g_2`$（$`A[2]`$） | $`f(0)`$ | $`y'_0`$ | $`y'_1`$ | $`z'_0`$ | $`z'_1`$ | $`f(1)`$ | $`f(2)`$ |

ラベルの順序は次のとおりである。

```math
f(0) \lt y'_0 \lt y'_1 \lt z'_0 \lt z'_1 \lt f(1) \lt f(2) \lt f(3)
```

高さは $`\mathrm{ht}(g_2) = f(2) \lt f(3) = \mathrm{ht}(f)`$ である。

ステップ $`q = 0`$ で、$`A[1] = (0,0)(1,1)(2,2)(3,1)(4,2)`$ の先祖の関係をいくつか確かめる（先祖は §5 の表の最初の 5 列と同じである）。

| 先祖の関係 | §6 の場所 | 理由 |
|---|---|---|
| 行 1 で $`1 \prec 2`$ | 2（$`B_0`$ の中） | $`\mathrm{rel}_1(f(1), f(2))`$ に (R5) を使い、$`\mathrm{rel}_1(y'_0, y'_1)`$ |
| 行 0 で $`0 \prec 2`$ | 2（左の先祖） | $`\mathrm{rel}_0(f(0), f(2))`$ に (R4) を使い、$`\mathrm{rel}_0(f(0), y'_1)`$ |
| 行 0 で $`2 \prec 3`$ | 3 (d)、$`j = 0`$ | $`\mathrm{rel}_0(f(2), \beta)`$ に (R6)（$`m = 0 \lt n = 1`$）を使い、$`\mathrm{rel}_0(y'_1, \alpha)`$ |
| 行 0 で $`2 \prec 4`$ | 3 (d)、$`j = 1`$ | $`\mathrm{rel}_0(y'_1, f(1))`$ と $`\mathrm{rel}_0(f(1), f(2))`$ から推移律 |
| 行 1 で $`0 \prec 3`$ | 3 (b) | $`0 \prec^A_1 1`$ から $`\mathrm{rel}_1(f(0), f(1))`$ |

$`A[1]`$ で、列 2 は行 1 では列 3 の先祖ではない（列 3 の行 1 の親は列 0）。だから $`\mathrm{rel}_1(y'_1, f(1))`$ は要らない。これは $`\mathrm{rel}_1(f(2), f(3))`$ が $`A`$ で求められていないこと（§2 の例）と合っている。

## 8. 停止性と整礎性

**定理（停止性）.** $`A`$ を $`r`$ 行の配列で、安定なラベルを持つものとする。$`n : \mathbb N \to \mathbb N`$ とし、展開列（[05](05-bms.md) §7）を次のように置く。

```math
A^{(0)} = A, \qquad A^{(t+1)} = A^{(t)}[n(t)]
```

このとき、ある $`T`$ で $`A^{(T)} = ()`$ である。

**証明.** どの $`A^{(t)}`$ も空でないとする。$`f_0`$ を $`A^{(0)}`$ の安定なラベルとする。命題 19.1 から、$`A^{(t+1)}`$ の安定なラベル $`f_{t+1}`$ で $`\mathrm{ht}(f_{t+1}) \lt \mathrm{ht}(f_t)`$ となるものを、$`t = 0, 1, \ldots`$ の順に選べる。

```math
\mathrm{ht}(f_0) \gt \mathrm{ht}(f_1) \gt \mathrm{ht}(f_2) \gt \cdots
```

集合 $`\{ \mathrm{ht}(f_t) : t \in \mathbb N \}`$ は空でない。$`\lt`$ は整列順序なので、最小元 $`\mathrm{ht}(f_{t_0})`$ がある。しかし $`\mathrm{ht}(f_{t_0 + 1})`$ はそれより小さい。これは矛盾である。$`\square`$

**系（整礎性）.** $`r`$ 行のどの配列も安定なラベルを持つとする。$`r`$ 行の配列の上の 1 段の展開の関係 $`\triangleleft`$（[05](05-bms.md) §7）を考える。

```math
A \mathrel{\triangleleft} B \iff B \ne () \ \wedge\ \exists N \in \mathbb N\ \ A = B[N]
```

このとき $`\triangleleft`$ は整礎である（[02](02-well-founded.md) §1）。

**証明.** $`\triangleleft`$ の無限降下列 $`C_0 \mathrel{\triangleright} C_1 \mathrel{\triangleright} \cdots`$ があるとする（$`\triangleright`$ は $`\triangleleft`$ の逆向き）。どの $`C_t`$ も空でなく、$`C_{t+1} = C_t[N_t]`$ である。これは空の項を持たない展開の列で、停止性の定理に反する。$`\square`$

**安定なラベルの出どころ.** 停止性の定理には、最初の配列 $`A^{(0)}`$ の安定なラベルが要る。出どころは 2 通りある。

- BM4 の元は、$`E_r = (0, \ldots, 0)(1, \ldots, 1)`$ から展開をくり返して得られる配列である（[05](05-bms.md)）。$`E_r`$ に安定なラベルがあれば、命題 19.1 から、BM4 の元はすべて安定なラベルを持つ。[bms-elem-pattern](https://github.com/koteitan/bms-elem-pattern) はこの方法を使う。
- このリポジトリでは、どの配列も安定なラベルを持つ（[08](08-closure-chain.md)、[09](09-obligations.md)）。すべての $`k`$ で $`i \lt j \implies \mathrm{rel}_k(\gamma_i, \gamma_j)`$ となるラベルの列 $`\gamma_0 \lt \gamma_1 \lt \cdots`$ を作り、列 $`i`$ に $`\gamma_i`$ を付けるからである。[08](08-closure-chain.md) と [09](09-obligations.md) では、この列を $`c_0 \lt c_1 \lt \cdots`$ と書く。

BM4 の元は $`r`$ 行の配列なので、BM4 の上の展開の関係も整礎である。展開は行数を変えないので、すべての行数を合わせた BM4 の上でも整礎である。

## 9. 意味の層に残る仕事

組合せの層は、有限反映がなぜ成り立つかを問わない。条件 1〜3 を満たすラベルの約束と、配列の安定なラベルを与えるのが、**意味の層** の仕事である。

| 証明 | ラベル | 関係 $`\mathrm{rel}_k`$ |
|---|---|---|
| DH の論文 | 許容順序数（構成可能階層 $`L`$ を使う） | $`L_\alpha \prec^*_{k+2} L_\beta`$（DH の論文の式 (15.1)） |
| [bms-elem-pattern](https://github.com/koteitan/bms-elem-pattern) | 順序数 | Carlson の $`\mathcal R_N`$ の $`\lt_{k+1}`$（$`\Sigma_{k+1}`$ 初等性） |
| このリポジトリ | 順序数 | [07 関係 R](07-relation-r.md) の $`R(k, \cdot, \cdot)`$（$`\Sigma_1`$ 初等性だけ） |

このリポジトリでの条件 1〜3 の証明は [09](09-obligations.md) にある。
